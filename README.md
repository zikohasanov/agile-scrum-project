# Agile Scrum Project — Portfolio Simulation

> Self-initiated simulation for a fictional restaurant ordering product. This is not evidence of participation in a real Scrum team or client delivery.

This package shows how a small analysis effort might be organized into a product goal, ordered backlog, two learning-focused sprints, and a review. It intentionally avoids fabricated velocity or completed-project claims.

- [Product goal and working agreements](product-goal.md)
- [Product backlog and sprint plan](backlog.md)
- [Review, retrospective, and metrics](review-retro.md)

The example separates delivery progress from outcome evidence. Story points are omitted because there is no real team calibration; capacity is expressed as a planning assumption only.
